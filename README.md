BandwagonHost 官方将服务描述为 self-managed。也就是说，系统安全、软件更新、服务配置、日志清理、备份恢复和故障排查主要由用户负责。

2.5 Gbps、5 Gbps 或 10 Gbps 是端口上限，不代表单个网站一定能跑到对应速度。实际速度还取决于 CPU、磁盘、应用程序、连接数、对端网络和流量类型。

如果你部署的是普通企业站或博客，端口速度通常不是首要瓶颈。内存、数据库查询、缓存策略和页面资源大小更值得优先检查。

VPS 价格、库存、计费周期和可选机房都可能调整。官方页面当前公开的圣何塞配置和价格，应以实际订单页为准。尤其是小规格套餐，页面可能只开放季度或更长计费周期；高规格套餐也可能因为库存状态改变而暂时不可购买。
